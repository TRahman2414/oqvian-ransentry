# Showcase Walkthrough (5–7 minutes)

1. Show the Overview and explain the Meridian Business Services fictional demo root. Point out the local watcher badge and synthetic-data label.
2. Open Integrity, capture/show the baseline count and sample SHA-256 evidence.
3. Start the local observer and verify its status.
4. Run the harmless single-change scenario. Show the integrity delta and why it remains informational.
5. Run the modification-burst scenario. Show distinct paths, the 10-second R001 threshold, and persistent evidence.
6. Add the separately simulated backup-disablement warning. Show R005/R006 correlation and the transparent priority explanation.
7. Open the incident and review event chronology, affected file paths, and score factors.
8. Demonstrate acknowledgment, an analyst note, and a database-only response preview labeled simulated/human approval required.
9. Reset the owned fixtures, recapture and verify the baseline. Confirm no unrelated directories are targeted.
10. State clearly that live endpoint agents, real backup connectors, and real remediation are future production work, not part of this demo.
