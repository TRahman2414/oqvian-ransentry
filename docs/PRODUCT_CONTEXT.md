# Product Context

OQVIAN RANSENTRY is a local-first defensive showcase for early warning from file-integrity deviations and high-rate filesystem operations, with fictional backup service context. The target demo audience includes business IT/security teams, service providers, and firms that rely on shared office files.

The demo uses a fictional Meridian Business Services tenant and disposable text/CSV/JSON fixtures. Its value is the combined workflow: observe real safe local file changes, explain rule matches, correlate with explicitly simulated backup warnings, and provide an evidence-led analyst workspace.

This is not a complete anti-ransomware engine. It does not monitor customer folders, protect remote servers, identify the operating-system process responsible for a file operation, connect to a real backup service, or automatically contain an endpoint. Heuristic thresholds are demo defaults and are not validated universal thresholds or probabilities.
