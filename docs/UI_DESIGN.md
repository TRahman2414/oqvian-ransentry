# OQVIAN RANSENTRY — Approved UI Direction

The approved concept uses a light, editorial operations-console layout: warm stone surfaces, ink-blue typography, quiet slate charts, orange for attention, and teal for healthy state. It keeps incident evidence and system health visible without relying on neon cyber styling. The mockup is a visual direction; production labels and live values must come from the local API.

![Approved OQVIAN RANSENTRY dashboard design concept](../assets-dashboard-preview.webp)

Implementation should preserve the information hierarchy and palette while ensuring responsive behavior, accessible contrast, keyboard navigation, and clear distinction between observed local file events and simulated backup/response records.
